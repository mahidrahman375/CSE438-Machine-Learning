# CSE 375: Machine Learning

This repository documents my laboratory work, assignments, experiments, and learning progress for **CSE375 – Machine Learning** at **East West University**.

It includes implementations of machine learning pipelines, supervised and unsupervised learning algorithms, ensemble methods, neural networks, optimization techniques, and deep learning models. The goal of this repository is to build a strong practical foundation in both classical machine learning and modern deep learning approaches.

---

## 🎯 Course Objectives

* Understand the full machine learning pipeline from raw data to model deployment
* Implement supervised, unsupervised, and ensemble learning models
* Analyze model performance using proper evaluation metrics
* Explore optimization techniques and loss functions
* Build and compare neural network and CNN architectures

## 🧪 Laboratory Experiments

### Experiment 1: ML Workflow and Data Preparation

* Data loading (CSV)
* Handling missing values and outliers
* Encoding categorical variables
* Feature scaling (normalization/standardization)
* Train-test split

---

### Experiment 2: k-NN and Decision Tree

* k-NN and Weighted k-NN
* Decision Tree (CART)
* Hyperparameter tuning
* Performance comparison (accuracy, precision, recall, F1-score)

---

### Experiment 3: Ensemble Learning

* Bagging and Random Forest
* AdaBoost and XGBoost
* Voting and Stacking classifiers
* Cross-validation comparison

---

### Experiment 4: Model Evaluation

* Confusion matrix
* Accuracy, Precision, Recall, F1-score
* K-Fold and Stratified K-Fold validation
* Stability analysis across folds

---

### Experiment 5: Clustering Techniques

* K-Means clustering
* Hierarchical clustering
* DBSCAN
* WCSS and Silhouette Score evaluation

---

### Experiment 6: Association Rules and Dimensionality Reduction

* Apriori algorithm
* Association rule mining
* PCA and t-SNE visualization
* Feature space comparison

---

### Experiment 7: Anomaly Detection

* Z-score method
* Isolation Forest
* Outlier visualization and comparison

---

### Experiment 8: Loss and Activation Functions

* MSE, MAE, Huber, Cross-Entropy loss
* Sigmoid, ReLU, Leaky ReLU, Softmax
* Convergence behavior analysis

---

### Experiment 9: Optimizers

* Gradient Descent, SGD, Mini-batch GD
* Momentum and Adam optimizer
* Loss curve comparison

---

### Experiment 10: ANN and CNN

* Artificial Neural Networks (ANN)
* Convolutional Neural Networks (CNN)
* Pooling, dropout, regularization
* Advanced convolutions (dilated, transposed)

---

### Experiment 11: CNN Architecture Comparison

* Vanilla CNN baseline
* Depthwise separable convolution
* Dilated convolution
* Grouped convolution
* Performance vs efficiency trade-off
